平台定位

EdgeOS 作为 EdgeX 的上层应用平台，基于 EAN 2.0 Capability 模型承载发现、编排、治理与事件订阅。

协调平面

部署于服务器或高性能边缘网关之上，通过 $edgeos/* Topic 纳管 EdgeX 节点，承担全局发现索引与跨节点编排。

  • Agent / Capability 发现与索引
  • 跨节点 Invoke 编排与 Reply 关联
  • V1 兼容层并行运行

群控与调度

支持大规模 EdgeX 节点的群控管理与协同调度，实现跨节点、跨场站的统一策略执行。

  • 多节点批量配置下发
  • 策略模板与场景联动
  • 分布式任务编排

事件与治理

订阅 EdgeX 上报的设备事件（含 previous_value），按租户策略约束写/admin/AI 能力，跨节点调用全程留痕。

  • Event 订阅与 previous_value 比较
  • 租户级权限与审计
  • 心跳超时与离线判定

核心能力

围绕发现、编排、事件与治理构建 EAN 2.0 协调平面，覆盖 EdgeOS 的核心能力与落地方向。

发现与索引

订阅 $edgeos/discovery/* 建立 Agent 与 Capability 索引，原生 EAN 优先于 V1 合成，60 秒周期重发布。

  • Agent / Capability / Offline 三级索引
  • source 优先级：native-ean > v1-bridge
  • 主动查询与递减频率

Invoke 编排

通过 correlation_id + invoke_id 关联 Invoke 与 Reply，EAN 超时后自动回退 V1 协议，40%/60% 时间预算分配。

  • Reply 订阅 $edgeos/reply/{planner_id}
  • EAN → V1 协议转译桥接
  • 跨节点调用审计留痕

事件订阅与治理

订阅 EdgeX 上报的设备事件，读取 value 与 previous_value，按租户策略约束能力调用，心跳超时判定离线。

  • device.online / device.offline 事件
  • 租户级写/admin/AI 权限
  • 心跳超时 3 × heartbeat_interval

业务场景

覆盖能源、交通、安防与运营领域，基于 EAN 2.0 Capability 模型落地垂直场景。

智能电网

电力设备状态监测、负荷预测分析、故障诊断与自愈控制，支撑电网运维。

充电储能场站

集中管理充电桩与储能系统，优化能源调度策略，实现场站级能量协同。

交通联合指挥

多源感知数据融合、实时路况分析、信号控制与应急指挥调度。

图像识别

边缘侧图像识别、缺陷检测、安全监控与视频结构化分析。

运营中心

集中监控大屏、告警统一管理、运维编排自动化与运营决策支持。

AI 能力

EdgeX 侧的 AI 能力通过 Capability Runtime 统一接入 EAN 2.0，EdgeOS 作为协调平面发起 Invoke 并约束权限。所有 AI 产出须经 Human-in-the-loop 确认后落库，不进入采集热路径。

Capability

ai.protocol_reverse

EdgeX 侧 AI Agent Client 基于抓包报文与 protocol_knowledge.db 生成候选协议配置，工程师确认后落库。将「2 天分析协议」缩短到「30 分钟生成候选 + 确认」。

报文捕获 → AI 候选配置 → Human Confirm → 落库
  • LLM/VLM/Embedding 由远端 AI Model Center 承担
  • protocol_knowledge.db 基于 bbolt 本地存储
  • 禁止 AI 调用进入 ScanEngine / Pipeline Worker
Capability

ai.doc_parse

解析设备手册、协议文档与点位表，自动提取寄存器映射与点位定义，生成可导入的物模型草稿。

  • 支持 PDF / Word / 扫描件输入
  • 输出符合 EdgeOS 物模型规范的 JSON
  • 产出须经工程师确认后写入
Runtime

Capability Runtime

EdgeX 侧的 AI Skill、MCP Tool、Driver Command、Workflow Node 统一映射到 Capability 模型，通过 Invoke Dispatcher 路由到对应执行器。

  • AI Adapter / MCP Adapter / DriverExecutor
  • Capability Registry 统一注册与发现
  • ShadowCore 提供状态缓存与 Event 上报
Governance

Human-in-the-loop

所有 AI 产出（协议配置、物模型、点位映射）禁止自动写入 config，必须经工程师确认后落库。AI 故障不得影响工业采集与规则执行。

  • AI Invoke 受 admin/ai 权限约束
  • 产出落库前需显式 Confirm / Apply
  • AI 调用与采集热路径物理隔离
