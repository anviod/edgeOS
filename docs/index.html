核心子系统

Capability 发现

订阅 $edgeos/discovery/* 建立 Agent 与 Capability 索引，60 秒周期重发布。

Invoke 编排

correlation_id + invoke_id 关联 Invoke 与 Reply，EAN 超时自动回退 V1 协议。

事件订阅

订阅设备事件并读取 previous_value，按租户策略约束写/admin/AI 能力。

治理审计

跨节点 Invoke 记录审计日志，心跳超时判定离线，Capability 来源优先级管理。

双传输链路

MQTT + NATS 并行传输，Topic/Subject 字符串一致，NATS 保留斜杠分隔符。

V1 兼容桥接

自动合成 V1 协议 Capability，原生 EAN 优先升级，跳过已存在原生能力的 Agent。

AI 能力

ai.protocol_reverse

基于抓包报文生成候选协议配置，工程师确认后落库。

ai.doc_parse

解析设备手册与点位表，自动提取寄存器映射，生成物模型草稿。

Human-in-the-loop

AI 产出禁止自动写入 config，受 admin/ai 权限约束，与采集热路径物理隔离。
